# LLM package map

- `core/`: leaf contracts (messages, requests, provider/tool/stream interfaces, usage, events, continuations, model-limit hooks and durable markers) and provider-neutral helpers. Import from here in new implementations. `core/stream/` owns event streams, SSE decoding and typed stream errors.
- `engine/`: turn loop, steering, continuation, compaction, handover, path notes, classification, tool registry and turn-limit policy. Root-only behaviour (model limits, debug output, provider unwrapping, non-recoverable stream errors) is injected through `engine.Env`/`engine.SetEnv` by root `engine_env.go`; model-limit lookups use `core.ModelLimits`. Applications using this root-owned policy must link root `llm` so its initialization runs. Do not import root `llm` from `engine/`.
- `factory/`: concrete inference constructors registered for `internal/providerspec` types. Root provider selection, retry and fast-target policies pass root-owned upload/model hooks through `factory.Options`; do not import root `llm` from `factory/`.
- `providers/anthropic/`, `bedrock/`, `clibin/`, `gemini/`, `ollama/`, `opencompat/`, `responses/`, `responsesproviders/`, `transcription/`: family-owned transports. `responses/` is the shared Responses API transport; `responsesproviders/` owns ChatGPT, OpenAI, Copilot, Grok, Zen and OpenCode Go. Provider families import `core` and shared transport packages, never root `llm`.
- `debug/`: debug provider, structured logger and browser fixture. `providerusage/`: usage probes and formatting. `schema/`: shared JSON schema model and lowering. `filemime/`: MIME canonicalization and accepted upload types. `mockprovider/`: scripted mock provider for engine tests.
- Root `llm`: model metadata, config-backed limits and policies, provider selection, retry and remaining cross-family wiring. Import the owning package directly for contracts, engine functions, and provider transports.
- Test the engine with `go test ./internal/llm/engine`, provider transports with `go test ./internal/llm/providers/...`, and root integration with `go test ./internal/llm`. Use isolated HOME for direct Go tests; run `make check-changed`, `make check-changed ARGS=--all` and `make complexity` for touched areas.
