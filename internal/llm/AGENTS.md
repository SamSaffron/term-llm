# LLM package map

- `core/`: leaf contracts (messages, requests, provider/tool/stream interfaces, usage, events, continuations, model-limit hooks and durable markers) and provider-neutral helpers. Import from here in new implementations. `core/stream/` owns event streams, SSE decoding and typed stream errors.
- `engine/`: turn loop, steering, continuation, compaction, handover, path notes, classification, tool registry and turn-limit policy. Root-only behaviour (model limits, debug output, provider unwrapping, non-recoverable stream errors) is injected through `engine.Env`/`engine.SetEnv` in root `engine_compat.go`; model-limit lookups use `core.ModelLimits`. Do not import root `llm` here.
- `factory/`: concrete inference constructors registered for `internal/providerspec` types. Root `factory.go` handles provider selection, retry and fast-target policies and passes root-owned upload/model hooks through `factory.Options`; do not import root `llm` from `factory/`.
- `providers/anthropic/`, `bedrock/`, `clibin/`, `gemini/`, `ollama/`, `opencompat/`, `responses/`, `responsesproviders/`, `transcription/`: family-owned transports. `responses/` is the shared Responses API transport; `responsesproviders/` owns ChatGPT, OpenAI, Copilot, Grok, Zen and OpenCode Go. Provider families import `core` and shared transport packages, never root `llm`.
- `debug/`: debug provider, structured logger and browser fixture. `providerusage/`: usage probes and formatting. `schema/`: shared JSON schema model and lowering. `filemime/`: MIME canonicalization and accepted upload types. `mockprovider/`: scripted mock provider for engine tests.
- Root `llm`: deprecated compatibility aliases/wrappers for existing callers (including `cmd/`), model metadata, config-backed limits and policies, retry and remaining cross-family wiring. New implementation code belongs in an owning package rather than root. Keep the root aliases until the parallel `cmd/` migration lands.
- Test the engine with `go test ./internal/llm/engine`, provider transports with `go test ./internal/llm/providers/...`, and root integration/compatibility with `go test ./internal/llm`. Use isolated HOME for direct Go tests; run `make check-changed`, `make check-changed ARGS=--all` and `make complexity` for touched areas.
