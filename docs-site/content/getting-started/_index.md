Start here for the shortest path from a fresh install to a working term-llm setup.

On macOS 14+, start with [term-llm for Mac](/getting-started/installation/#macos-app-recommended),
which manages the CLI and local web service. The [quickstart](/getting-started/quickstart/)
also covers terminal-only macOS installs, Linux, and Windows.
